In this lab, you will practice using higher-order functions in JavaScript. Higher-order functions are functions that can take other functions as arguments, or return functions as their output. Some commonly used higher-order functions in JavaScript include `map`, `filter`, and `reduce`. You will create higher-order functions and work with arrays to perform operations using these functions.
