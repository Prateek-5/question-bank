# JavaScript Prototypes Lab

- **#98** in the Codedamn Node.js list
- **Difficulty:** Medium
- **Source:** https://codedamn.com/problem/5xu9D9GLXOx2-723g9MNq
- **Starter repo:** https://github.com/mehulmpt/web-development-labs (branch `lab_1683286447`)

---

In this lab, you will work with JavaScript prototypes to create an Animal constructor function and a Dog constructor function that inherits from Animal. You will also modify and implement the `speak` function for each constructor to demonstrate how inheritance works in JavaScript.

Make sure to properly write your code in an ESM manner, as we're working in a Node.js 14 environment.
