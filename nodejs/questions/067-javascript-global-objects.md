# JavaScript: Global objects

- **#67** in the Codedamn Node.js list
- **Difficulty:** Easy

---

In this lab, you will be practicing the creation and usage of global objects and functions in JavaScript. Global objects and functions are directly accessible from any file in the project without the need for imports or exports. In JavaScript, you can create global variables directly in your script, and they will be accessible throughout the code. You will learn to create a global variable and call a global function.
