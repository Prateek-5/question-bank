# JavaScript Configuration Management

- **#97** in the Codedamn Node.js list
- **Difficulty:** Medium
- **Source:** https://codedamn.com/problem/5KbzgCHwPlPfqaZfoId7e
- **Starter repo:** https://github.com/mehulmpt/web-development-labs (branch `lab_1683285519`)

---

In this lab, your task is to create a JavaScript configuration management system using Node.js. You will create an 'index.js' file exporting a 'config' object with configurations such as 'host' and 'port'. In the process, you will also create a 'config.json' file with the same configuration and use the fs.promises API to read and log its contents in the console. This lab will help you understand the concepts of ES modules, configuration management, and working with the fs.promises API.
