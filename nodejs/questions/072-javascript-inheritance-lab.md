# JavaScript Inheritance Lab

- **#72** in the Codedamn Node.js list
- **Difficulty:** Easy
- **Source:** https://codedamn.com/problem/hFIrZbb9iAFEEcRx_0luM
- **Starter repo:** https://github.com/mehulmpt/web-development-labs (branch `lab_1683272445`)

---

In this lab, you will practice using JavaScript inheritance concepts by creating `Person` and `Student` classes. You will learn how to create classes, inherit from a parent class, and work with the `constructor`, `extends`, `super`, and `this` keywords. 

*Note:* Use ECMAScript 2015 (ES6) class syntax in this lab.
