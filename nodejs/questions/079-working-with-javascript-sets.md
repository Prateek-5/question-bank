# Working with JavaScript Sets

- **#79** in the Codedamn Node.js list
- **Difficulty:** Medium
- **Source:** https://codedamn.com/problem/jvPcQCGC7huVxjfs2XvPC
- **Starter repo:** https://github.com/mehulmpt/web-development-labs (branch `lab_1683273909`)

---

In this lab, you'll be practicing with JavaScript Sets. Sets are a built-in object that allows you to store unique values of any type. You'll create a Set, add elements to it, and implement two helper functions, `union` and `intersection`, that take sets and return the union or intersection of the input sets. Make sure to export these functions using ESM syntax.
