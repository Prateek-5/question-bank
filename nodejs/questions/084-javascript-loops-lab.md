# JavaScript Loops Lab

- **#84** in the Codedamn Node.js list
- **Difficulty:** Easy
- **Source:** https://codedamn.com/problem/DdxdsZGWoaQu8QoXFdUXR
- **Starter repo:** https://github.com/mehulmpt/web-development-labs (branch `lab_1683279092`)

---

In this lab, we will practice using different types of loops available in JavaScript. We will create and test functions that perform operations such as multiplying elements, filtering even numbers, and summing items in an array. We will use functions like `map`, `filter`, and `reduce` to iteratively process elements in an array.
