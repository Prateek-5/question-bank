In this lab, you will be using the `Reflect.deleteProperty()` method to delete a property from a JavaScript object. The `Reflect.deleteProperty()` method allows you to delete a property from an object while receiving the result as a boolean value representing the success of the operation. For instance, if the property is deleted successfully, it returns `true`; otherwise, it returns `false`. Your task is to create a target object, a function that uses `Reflect.deleteProperty()` to delete a given property, and export the updated object using ESM syntax.
