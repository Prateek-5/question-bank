# JavaScript - Implement a custom isTypedArray() function

- **#44** in the Codedamn Node.js list
- **Difficulty:** Medium
- **Source:** https://codedamn.com/problem/HKRJ6AketdSWTkewNplHu
- **Starter repo:** https://github.com/mehulmpt/web-development-labs (branch `lab_1683716140`)

---

In this lab, your task is to create a custom implementation of lodash's [`_.isTypedArray()`](https://lodash.com/docs/4.17.15#isTypedArray) function without using lodash. Your implementation should work similarly to lodash's isTypedArray().\n\nYour implementation should work with normal arrays as well as typed arrays like Int8Array, Uint8Array, etc.\n\nYou also need to write some unit tests for the custom `isTypedArray()` function using Node.js' built-in assert module.
