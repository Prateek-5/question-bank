# Javascript ES6 modules

- **#24** in the Codedamn Node.js list
- **Difficulty:** Easy
- **Source:** https://codedamn.com/problem/5pASnz55m_QVnlEMOqyQE
- **Starter repo:** https://github.com/mehulmpt/web-development-labs (branch `lab_1683274441`)

---

ES6 modules provide a better way of managing code. This lab will help you to learn how to create and export ES6 modules using the `export` keyword and how to import them using the `import` keyword. You will practice exporting a function from a `greetings.js` file and importing it into the `index.js` file.
