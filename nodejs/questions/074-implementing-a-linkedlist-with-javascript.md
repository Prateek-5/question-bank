# LinkedList Lab

In this lab, we will create a LinkedList by implementing `Node` and `LinkedList` classes. The `Node` class would have properties `value` and `next` to store the node data and the reference to the next node. The `LinkedList` class will have methods like `add` and `length` to perform operations on the list. We will be using the ESM syntax for this exercise.
