In this lab, you will be working with the built-in `path` module available in Node.js. `path` module provides utilities to work with directories and file paths. Your task is to write functions that perform file manipulations according to the challenges using the `path` module in a `main.js` file. Make sure to export every function so that it can be properly evaluated.
